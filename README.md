# 오늘의 계란

계란을 깨는 순간부터 팬을 움직이고 뒤집는 순간까지 손으로 직접 조작하는 모바일 퍼스트 2D 요리 게임입니다. 모든 활성 게임 장면을 Canvas 2D로 그리며, 굵고 둥근 선과 따뜻한 파스텔 색으로 화면 전체의 스타일을 통일했습니다.

## 게임 흐름

한 라운드는 현재 해야 할 행동 하나에 집중하도록 순서대로 진행됩니다.

1. 계란을 잡고 아래로 짧게 휘둘러 팬 림에 깨기
2. 팬을 좌우로 천천히 굴려 기름을 고르게 코팅하기
3. 익힘 표시를 보며 알맞은 순간 소금 치기
4. 팬을 아래에서 위로 빠르고 곧게 플릭해 계란 뒤집기
5. 목표 익힘 구간에서 접시에 담기

속도와 방향이 판정에 영향을 줍니다. 너무 약한 크랙은 다시 시도할 수 있고, 너무 강한 크랙·과격한 팬 움직임·늦거나 비뚤어진 플릭은 노른자 손상, 기름 튐, 흐트러진 모양과 감점으로 이어집니다. 실수하더라도 라운드는 중단되지 않으며, 손상된 후라이를 끝까지 살려 점수를 회복할 수 있습니다.

화력 전환과 버터 코팅은 뒤집기 흐름에 맞춰 자동으로 처리됩니다. 별도의 복잡한 화력·버터 조작을 외우지 않아도 됩니다.

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드는 `npm run build`, 빌드 미리보기는 `npm run preview`를 사용합니다. Chrome 또는 Edge가 설치된 환경에서는 `npm run test:smoke`로 실제 포인터 플레이, 결과 판정, 다크모드와 반응형 레이아웃을 자동 검증할 수 있습니다.

## GitHub Pages 배포

`main` 브랜치에 변경 사항을 푸시하면 GitHub Actions가 Pages 전용 경로(`/EGG/`)로 게임을 빌드하고 자동 배포합니다.

- 공개 주소: <https://monitari.github.io/EGG/>
- 워크플로: `.github/workflows/deploy-pages.yml`
- 로컬 Pages 빌드 확인: `npm run build:pages`

GitHub 저장소에서 최초 한 번 `Settings → Pages → Build and deployment → Source`를 **GitHub Actions**로 선택해야 합니다. 이후에는 `main` 브랜치에 푸시할 때마다 같은 주소가 자동 갱신됩니다. 일반 `npm run build`는 로컬 및 Capacitor용 설정을 그대로 사용하므로 모바일 빌드에는 영향을 주지 않습니다.

## 조작

### 마우스와 터치

- 크랙: 계란을 누른 채 팬 림 방향으로 아래로 휘두릅니다.
- 기름 코팅: 팬 조작 영역을 누른 채 좌우로 부드럽게 왕복합니다. 너무 빠르면 기름이 튑니다.
- 소금: 소금 버튼이 활성화되는 타이밍에 한 번 누릅니다.
- 뒤집기: 팬 조작 영역을 아래에서 위로 한 번에 플릭합니다.
- 담기: 목표 익힘 구간에서 완성 버튼을 누릅니다.

### 키보드

- 크랙: 계란에 포커스한 뒤 `Enter` 또는 `Space`
- 팬 굴리기: `←`/`→` 또는 `A`/`D`
- 소금: `F`
- 뒤집기: `↑`, `Enter` 또는 `Space`
- 담기: `Space`
- 돌발 상황 대응: `E`

## 난이도

- `연습`: 넓은 크랙·팬·플립 판정, 느린 조리, 60초, 점수 ×0.75
- `보통`: 두 번의 팬 방향 전환과 기본 조리 속도, 52초, 점수 ×1.0
- `집중`: 더 정교한 크랙과 세 번의 팬 방향 전환, 빠른 플립, 42초, 점수 ×1.4
- `아슬`: 좁은 속도·방향·익힘 판정과 네 번의 팬 방향 전환, 34초, 점수 ×2.0

난이도가 높아질수록 크랙의 적정 충격과 좌우 오차, 기름 코팅 속도, 플립 속도와 타이밍 구간이 좁아집니다. 난이도별 최고 점수는 따로 저장됩니다.

## 점수와 수집

크랙 정확도, 기름 코팅, 소금 타이밍, 뒤집기, 흰자·노른자·가장자리 익힘과 남은 시간을 종합해 점수를 계산합니다. 완벽한 구움은 높은 점수를 주고, 덜 익거나 너무 익거나 조작이 과격할수록 감점됩니다.

완성 횟수, 난이도, 누적 점수, 크랙 손맛, 조리 기술, 돌발 대응과 연속 무손상 등을 다루는 업적 48개가 있습니다. 업적으로 다음 스킨을 각각 해금하고 장착할 수 있습니다.

- 계란 스킨 6종
- 프라이팬 스킨 6종
- 주방 배경 스킨 6종

업적 진행도, 해금 상태, 장착한 계란·팬·배경과 최고 점수는 브라우저 저장소에 유지됩니다.

## 그래픽과 화면 대응

- 모든 활성 게임 장면을 Canvas 2D 일러스트로 렌더링
- 크랙, 팬 코팅, 소금, 뒤집기, 플레이팅별 클로즈업 구도
- 파스텔 팔레트, 단순한 굵은 윤곽과 눌림 그림자
- 계란의 익힘, 기름, 소금, 팬 기울기, 흔들림과 플립 궤적을 시각적으로 표현
- 라이트·다크 모드와 사용자 선택 저장
- 세로폰, 짧은 가로폰, 태블릿과 울트라와이드 레이아웃
- 터치 히트 영역, 포인터 취소와 앱 전환 복구
- 키보드 대체 조작, 포커스 표시, ARIA 상태와 모션 감소 설정
- 저사양 기기의 Canvas 해상도와 효과 자동 절약

## 모바일 앱 빌드

Capacitor 8.4.2 기반 Android 패키징 설정이 준비되어 있습니다. 현재 `com.eggcellent.kitchen`은 임시 앱 ID이므로 네이티브 프로젝트를 만들기 전에 [capacitor.config.json](./capacitor.config.json)의 `appId`를 본인이 소유한 역도메인 ID로 변경하세요.

```bash
npm install
npm run cap:add:android
npm run cap:sync:android
npm run cap:open:android
```

Windows와 VS Code에서 Android 앱을 빌드할 수 있습니다. iOS 빌드와 서명에는 macOS와 Xcode가 필요합니다. 최초 설치, 실기기 테스트, 아이콘과 릴리스 서명 절차는 [MOBILE_BUILD.md](./MOBILE_BUILD.md)를 참고하세요. 저장소에는 아직 `android/` 네이티브 프로젝트를 생성하지 않았습니다.

## 코드 구조

- `src/game/Game.js`: 상태 머신, 난이도 규칙, 게임 루프, 팬 제스처와 점수 판정
- `src/game/KitchenScene2D.js`: Canvas 2D 주방, 팬·후라이·기름·소금·플립 애니메이션
- `src/game/CrackController.js`: 크랙 스윙의 속도·가속도·방향 판정
- `src/game/Vector.js`: 게임 상태와 2D 장면이 공유하는 좌표 유틸리티
- `src/game/CosmeticsSystem.js`: 계란·팬·주방 스킨 해금, 장착과 저장
- `src/game/UI.js`: 난이도 선택, HUD, 제스처 안내, 결과 화면과 접근성 상태
- `src/game/AchievementSystem.js`: 48개 업적, 누적 통계, 해금과 저장
- `src/game/SoundManager.js`: Web Audio 기반 효과음과 지글거림
- `src/game/config.js`: 난이도별 크랙·팬 코팅·플립·익힘 판정
